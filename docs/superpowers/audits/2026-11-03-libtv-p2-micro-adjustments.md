# LibTV P2 微调验收

## 范围

只处理剩余 P2 中已有明确证据的细节，不重做画布或故事板结构：

- 故事板选择计数从去重节点数改为实际素材数，避免图片备选共享同一 `nodeId` 时少计。
- 390px 下素材选择按钮增至 28px，模块折叠按钮增至 32px，在画布中处理按钮增至 36×36px 并提供无障碍名称。
- 默认和选中连线统一为约 2px，移除选中发光，保留颜色与透明度层级。
- 节点悬浮工具条降低阴影强度。

## 浏览器验收

- 1440×900 和 390×844、DPR 3 下故事板无横向溢出。
- 选择一张图片后显示“已选 1 个素材”，选择按钮桌面 20×20px、移动端 28×28px。
- 移动端模块折叠按钮为 32×32px，在画布中处理按钮为 36×36px。
- 空文本、空图片和空视频状态仍只显示单条说明。
