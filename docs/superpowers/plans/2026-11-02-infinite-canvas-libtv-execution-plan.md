# Infinite Canvas LibTV 对标执行计划

**目标:** 在保留 Infinite Canvas 自有画布、节点能力和品牌体系的前提下，落地 LibTV 最值得借鉴的“工作流 / 故事板双视角”、画布降噪和复杂画布导航能力。

**边界:** 不复制 LibTV 的源码、图标、字体、素材和公开项目内容；不把画布迁移到 React Flow；不建立第二份故事板业务数据；本轮不调用真实付费模型、不部署生产。

**交付状态:** 实现已提交 `1d6ec9f` 并推送到 PR [#20](https://github.com/Smithhss/infinite-canvas/pull/20)。Quality CI 已通过，尚未合并或部署生产。

## Phase 1 验收

- 同一节点在画布和故事板中保留相同 `nodeId`。
- 故事板从现有 `CanvasProject.nodes` 纯计算生成，不写回第二份业务数据。
- 文本、图片、视频模块独立滚动、搜索、筛选和折叠。
- 图片和视频保留原始画面，不修改节点内容。
- 点击“定位到画布”后切回工作流并聚焦原节点。
- 桌面和 390px 移动端无横向溢出。

## Phase 2 验收

- 连线显隐不修改项目中的 `CanvasConnection[]`。
- 缩放滑杆保留，同时支持 50%、100%、适合屏幕。
- 小地图、连线显隐和缩放控制不遮挡画布核心操作。

## Phase 5 执行前置

公开只读分享不能只靠前端实现，必须先冻结以下契约：

- 项目快照的规范化序列化格式，以及图片、视频、音频资源的存储和迁移策略。
- 分享链接的凭证形式、过期时间、撤销方式和访问审计字段。
- `owner`、`viewer`、`editor` 的权限边界，以及节点锁与项目权限同时生效时的优先级。
- 复制公开画布的授权规则：是否允许复制、复制后是否保留来源、如何隔离收费模型调用和本地凭证。
- 服务端版本号、冲突检测和只读页面的降级行为；未知版本或损坏快照必须拒绝覆盖。

Phase 5A/5B 可以独立于服务端实施，但节点锁必须是持久化节点字段，并由所有交互入口共同校验，不能只隐藏按钮。

## Phase 5A/5B 验收

- 节点锁保存为持久化节点字段，刷新后保持状态。
- 锁定节点禁止拖动、缩放、删除、内容/标题/配置编辑、生成与重试、素材替换、批量图片删除和连线变更。
- 视频截帧、裁剪、切图、蒙版、放大和角度生成等会新增关联连线的派生操作同样校验节点锁。
- 查看信息、下载、存资产、选择和仅移动画布不受节点锁影响。
- 清空画布保留锁定节点及其互相之间的连线。
- Agent 操作和 Agent undo 快照不能修改后来被锁定的节点或删除其关联连线。
- 画布复制生成独立项目 ID 并深拷贝节点、连线和项目配置，原画布不被修改。

## Phase 6 启动条件

- Phase 5A/5B 完成并通过桌面、移动端和键盘操作回归。
- FYT 接口、鉴权、计费、错误码和回滚方案有当前版本的服务端契约。
- 供应商验收使用零收费 mock 或明确额度的真实调用，并记录模型、单价、实际扣费、退出 IP 和失败原因。
- 生产发布前单独取得授权，不把 PR 合并授权等同于生产部署授权。

## 执行阶段约束

- 实现和验收阶段不提交、不推送、不部署；提交与推送在用户另行授权后执行。
- 不调用真实收费模型。
- 不修改 FYT、生产数据库、Nginx 或线上容器。
- 不引入新依赖。

## 执行结果

- 故事板仅从现有 `CanvasProject.nodes` 投影，没有新增第二份业务数据。
- 文本、图片和视频模块支持搜索、状态筛选、折叠、详情与定位回画布；图片备选保留各自 `itemId` 和共同 `nodeId`。
- 故事板多选可切回工作流并复用现有选中态、打组和解组能力。
- 连线显隐只影响渲染，不修改 `CanvasConnection[]`。
- 缩放控制新增 50%、100% 和适合屏幕，并修复故事板定位回画布时容器尺寸尚未恢复导致缩放到 5% 的问题。
- 保存状态与跨标签冲突提示已通过两个真实标签页验证；公开分享和权限保护仍等待服务端契约。
- Phase 5A 节点锁和 Phase 5B 本地画布复制已完成；锁定后的拖动、删除、刷新持久化、解锁恢复、画布复制和窄屏布局已通过浏览器验证。
- Ego Browser 回归覆盖配置、视频、图片、文本、音频和组节点：锁定后仅保留只读操作；图片节点快捷工具栏固定保留锁定/解锁入口；锁定视频右键菜单不再提供截帧；拖动、删除、清空、刷新和连线入口均受保护。
- 复制后的测试画布保留 6 个锁定节点，原画布仍保持 5 个节点和 1 条连线；清空画布只保留锁定节点，解锁后节点删除能力恢复。
- 深色桌面与 390px 深色布局均无页面横向溢出或固定工具栏越界，移动端新页面默认收起左侧面板。
- 最新全量自动化验证为 122 个测试通过、TypeScript 类型检查通过、Vite 生产构建通过、`git diff --check` 通过。
- PR Quality CI（run `41585499344`）已通过，覆盖 Web 测试、类型检查、standalone/FYT-managed 构建、Docs 类型检查和 whitespace。
- Phase 5C 公开只读分享和跨设备复制仍阻塞于服务端项目存储、权限、分享凭证、撤销和审计契约。
